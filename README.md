## 📲 如何在手机上添加到主屏幕（原生 App 级体验）

本项目已完全支持 **PWA（Progressive Web App）**：
1. **iPhone / iPad (iOS Safari)**：
   - 用 Safari 浏览器打开上述网址；
   - 点击浏览器底部的 **“分享”** 按钮（方框带向上箭头）；
   - 在菜单中向上滑动，点击 **“添加到主屏幕”** ➔ 点击右上角 **“添加”**；
   - 桌面即可生成专属图标，全屏无地址栏沉浸式启动！
2. **Android 手机 (Chrome / Edge / 微信等)**：
   - 打开网址后，点击右上角 **“...”** 菜单；
   - 选择 **“添加到主屏幕”** 或 **“安装应用”** 即可。

## 🔐 核心安全特性

1. **零知识端到端加密**：
   - 浏览器原生 `Web Crypto API`（`PBKDF2` 100,000次迭代派生密钥 + `AES-256-GCM` 算法）；
   - 所有个人信息、书签备注、备忘笔记、财务流水全部在本地内存加密后再持久化，除主控密码外无人可解密。
2. **多端防爆破与自动锁定**：
   - 连续输错密码自动启动阶梯式冷却倒计时；
   - 支持无操作自动超时锁定与一键快速锁屏。
3. **数据主权与云同步**：
   - 本地 `IndexedDB` 密态持久化存储；
   - 支持通过 GitHub Gist API 一键推送（Push）与拉取（Pull）加密数据包，实现手机与电脑无缝同步；
   - 支持全量导出 `.enc.json` 离线密态备份。
